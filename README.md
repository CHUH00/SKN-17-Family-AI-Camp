## 📌 프로젝트 개요
본 저장소는 **SKN-17 Family AI Camp** 과정을 수료하며 진행한 데이터 분석 및 인공지능 실습 내용을 집대성한 지식 보관소입니다. Python의 기초 문법부터 시작하여 머신러닝, 딥러닝, 자연어 처리(NLP)를 거쳐 대규모 언어 모델(LLM) 활용 서버 아키텍처 구축까지, AI 핵심 기술 전반을 체계적으로 실습하고 기록했습니다.

## 📂 저장소 구조 및 커리큘럼
이 저장소는 학습 목표 및 기술 스택별로 모듈화되어 있습니다. 각 폴더는 특정 도메인의 실습 코드와 관련 개념을 포함하고 있습니다.

| 폴더명 | 학습 내용 | 주요 기술/키워드 |
| :--- | :--- | :--- |
| **`python_basic`** | Python 언어의 기초 문법 및 활용 | 변수, 자료형, 부울 논리, 클래스, 객체 지향 프로그래밍(OOP) |
| **`data_analysis`** | 데이터 전처리 및 탐색적 데이터 분석(EDA) | NumPy, Pandas, Matplotlib, Seaborn |
| **`web_crawling`** | 웹 데이터 추출 및 외부 API 연동 파이프라인 | Requests, BeautifulSoup, Selenium, REST API |
| **`machine_learning`** | 전통적 머신러닝 모델의 수학적 이해 및 구현 | 회귀(Regression), 분류(Classification), 군집화, 앙상블 학습 |
| **`deep_learning`** | 신경망 구조의 원리 이해와 기초 모델 구현 | Perceptron, 오차역전파, 활성화 함수, CNN, RNN |
| **`natural_language_processing`** | 자연어 처리 기반 기술 및 언어 모델 분석 | 형태소 분석, 토큰화, Word Embedding, LSTM, 텍스트 분류 |
| **`large_language_model`** | 현대적 LLM 아키텍처 설계 및 프롬프트 엔지니어링 | OpenAI API, RAG, 벡터 데이터베이스, Fine-tuning |
| **`database`** | 데이터 영속성 관리 및 시스템 연동 | SQL(CRUD, JOIN), RDBMS 설계, Python-MySQL 인터페이스 |
| **`front_end`** | AI 프로덕트 제공을 위한 웹 인터페이스 구축 | HTML, CSS, JavaScript (Vanilla JS) |
| **`back_end`** | 지능형 서비스를 위한 견고한 서버 아키텍처 | Django 프레임워크 구축, API 엔드포인트 설계 |

## ✨ 주요 성과 및 목표
1. **AI 지식의 시스템화**: 방대하고 흩어지기 쉬운 AI 학습 개념들을 논리적인 트리 구조로 재정립하여 접근성과 재사용성을 극대화했습니다.
2. **실무 데이터 기반 실습**: 단순히 이론만 넘기는 것이 아니라, 현장에서 쓰이는 실제 데이터를 로드하여 코드로 돌려보는 실전(Hand-on) 중심의 이해를 추구했습니다.
3. **지속 가능한 포트폴리오**: 훈련 캠프가 종료된 이후에도 개인적으로 심화 연구(Research)한 자료를 지속해서 푸시(Push)할 예정인 살아있는 오픈소스 포트폴리오입니다.
